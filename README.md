# Research Review Writer

**理清综述逻辑，写出贴近参考论文风格的英文。**

一个面向生物医学综述的写作 Skill，支持中文转英文、英文润色、章节重构和批注修改。结合你的原稿与论文参考库，分别优化论述组织和语言表达。

[安装](#安装) · [使用](#使用) · [工作流程](#工作流程) · [文档](#文档)

## 功能

- **理顺论述**：明确每段主旨，调整句序、段落衔接和材料取舍。
- **学习参考风格**：按研究领域、章节和写作目的选择库内范例，借鉴段落推进、措辞和句式。
- **中文确认后写英文**：涉及结构调整时，先给出完整中文稿；确认后据此组织自然英文。
- **核对事实与引用**：保留数字、条件与证据强度，检查论断和引用的对应关系。
- **落实作者批注**：逐条修改，交付正文与简短修改说明。

## 安装

下载本仓库后，在仓库目录运行：

```bash
npx skills add . --skill research-review-writer -a codex -g
python -m pip install -r requirements.txt
```

需要 Node.js 22.20+ 和 Python 3.11+。第一条命令通过 [skills CLI](https://github.com/vercel-labs/skills) 安装到 Codex，第二条安装 Python 依赖。

## 使用

准备原稿、修改要求和论文参考库，在 Codex 中调用 `$research-review-writer`。

首次使用时，按[参考库配置说明](references/corpus-setup.md)接入自己的材料。参考库保存经过核对的论文段落，以及论述方式、措辞和句式的标注；配置完成后可重复用于后续稿件。

### 翻译与润色

```text
使用 $research-review-writer 将附件中的中文引言写成英文。
保留已确定的事实、论证关系和段落顺序，参考库内同领域引言的措辞与句式。
输出英文稿和修改说明。
```

### 结构优化

```text
使用 $research-review-writer 重构附件中的章节。
每段先明确论述重点，再展开证据和解释，理顺段落之间的衔接。
必须保留的逻辑是：[填写你的论述主线]。
先给我完整中文稿，等我确认后再写英文。
```

### 按批注修改

```text
使用 $research-review-writer 按附件批注修改稿件。
沿用已经确认的结构与事实，逐条落实本轮意见。
输出英文清稿、Word 修订稿和修改说明。
修改说明只写具体改动和引用是否正常保留。
```

可以补充目标期刊、重点参考论文、篇幅和交付格式。长文可按章节处理，并统一术语与引用。

## 工作流程

**阅读原稿与要求 → 整理事实和引用 → 选择参考范例 → 优化中文结构 → 作者确认 → 英文写作与审阅**

结构已经确定的稿件直接进入翻译或润色。需要重组时，先确定各段主旨和前后关系，再展开完整正文。中文确认后，英文沿用确认的内容与逻辑，根据参考范例调整句式和表达。

材料取舍服务于论述。保留的论点携带相应证据，重复或偏离主旨的内容可以调整，并记录原因。参考范例的原文位置与采用理由随工作记录保存，需要时可以逐段查看。

## 输出

| 文件 | 内容 |
| --- | --- |
| 中文结构稿 | 可直接阅读和修改的完整正文，用于确认论述。 |
| 英文清稿 | 根据确认内容完成的英文正文。 |
| Word 修订稿 | 按需交付，显示原文与改稿之间的增删。 |
| 修改说明 | 具体改动及引用检查结果。 |

Word 清稿和修订稿由配套文档工具生成。事实台账、来源对应和详细审阅记录保存在工作目录中。
